# Reference Provenance

Route: `spinal_reference_adapter`.

Reference TOP source: `project-2.2-logisim/proj_2_2_top_solution.circ`.

The reference CSV is generated by installing the Spinal/Yosys Logisim netlist as `testing/circ_files/proj_2_2_top.circ`, running `p22_localtest.circ` through Logisim table mode, and applying the same mask policy used by the grader.

Mask rules:

- `count`, `PC`, `memWriteEnable`, and `regWriteEnable` are always checked.
- During grading, `regWriteAddress` and `regWriteData` are checked dynamically when `regWriteEnable == 1` in either the reference or student row.
- During grading, `memAddress`, `memWriteData`, and byte-enable fields are checked dynamically when `memWriteEnable == 1` in either the reference or student row.
- `memReadData` is intentionally not checked. Load correctness is checked through the later `regWriteData` result.
- Load `memAddress` is intentionally not checked.
- Unchecked fields are represented as `x` in the reference CSV. The grader applies enable-based dynamic masking at comparison time; no separate `reference_mask` file is used.

The p2.2 reference intentionally follows the pipelined Spinal adapter timing, not the older p2.1 single-cycle table timing.
